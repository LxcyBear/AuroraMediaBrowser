## Aurora Media Browser

I know a lot of people including myself got quite annoyed and sad when the Skin Downloader, which has been a part of Aurora for quite some time now on the homebrew store.. 
it just does not work. For that reason, I had Aurora Media Browser whipped up! Download skins, backgrounds and cover layouts in a few clicks, directly to your Aurora 
directory!

I know I am surely missing some skins and other elements that have been shared with the community. Please feel free to let me know here on the GitHub or Reddit/Discord, as 
this collection is surely to grow in size.
